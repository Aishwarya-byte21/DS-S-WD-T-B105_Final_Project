# Browser_history_analyser
# Time-Based Browsing Pattern Analyzer using Deep Learning with RAM Usage Correlation

## Project Overview
This project analyzes user browsing behavior patterns using Machine Learning and Deep Learning techniques along with RAM usage correlation. The system identifies browsing habits, detects unusual activities, analyzes memory-heavy browsing sessions, and provides useful productivity recommendations.

---

## Features
- Browsing history analysis
- Time-based behavior analysis
- Sessionization using inactivity threshold
- RAM usage correlation analysis
- KMeans clustering for behavior grouping
- Autoencoder-based anomaly detection
- Recommendation engine for productivity improvement
